# Code of Conduct

## Our standard

This project expects respectful, technical, and constructive collaboration.

Examples of behavior that help the project:

- Be direct and specific about bugs, tradeoffs, and design concerns.
- Assume good faith and discuss code and behavior, not people.
- Accept feedback, corrections, and review comments without escalation.
- Keep proposals grounded in evidence: failing tests, benchmarks, traces, or concrete use cases.
- Make room for contributors with different levels of experience.

Examples of unacceptable behavior:

- Harassment, threats, intimidation, or discrimination.
- Personal attacks, insults, or derogatory language.
- Deliberate disruption of discussions, reviews, or issue threads.
- Publishing private information without explicit permission.
- Repeated bad-faith arguments after maintainers have made a decision.

## Scope

This Code of Conduct applies in all project spaces, including issues, pull requests,
discussions, review comments, chat, and any public or private project-related
communication.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions,
or temporarily or permanently restrict participation for behavior that violates
this Code of Conduct.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
maintainers through GitHub private reporting or by contacting support@obleth.com.
Reports will be reviewed as promptly as possible.
